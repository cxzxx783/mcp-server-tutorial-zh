# 04 - 实战案例

> 真实能用的 MCP Server 案例，拿来就能跑、改改就能用。

| 案例 | 功能 | 难度 | 代码量 |
|------|------|------|--------|
| [📂 文件读取器](./file-reader/) | AI 读取本地文件内容 | ⭐ | ~50行 |
| [🌐 网页搜索器](./web-search/) | AI 搜索百度/网页 | ⭐⭐ | ~80行 |

**怎么用：**
1. 进对应目录看 `README.md`
2. `pip install -r requirements.txt` 装依赖
3. `python server.py` 启动 Server
4. 配到客户端（见 [05 注册与配置](../05-注册与配置/README.md)）
